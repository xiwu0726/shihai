# 诗海 · 中国诗词全集（单机版 v1.2）

一个免安装的 Windows 桌面应用：内嵌 **42.0 万篇**（420,200 篇）诗词曲文、**1.6 万位**（16,648 位）作者小传，从诗经到现代诗，支持全文搜索、繁简对照、通行本异文、注释与简析、名句标注、暗色模式。断网可用，所有内容都在这一个文件里。

## v1.2 新增：全新首页与阅读体验

**四段式首页**：顶栏真实统计（`420,200 首 · 16,648 位作者 · 含现代诗 81,699 首`）+ 检索入口；**12 段朝代时间轴**（先秦 → 现代，按真实篇数绘制）；「传世名篇」每天换一首的今日一诗；「诗人星河」——收录存诗 4 篇以上的 **2,000 位**诗人，可拖拽平移、滚轮以光标为锚缩放、点星进作者页，并有「全景 / 自转 / 随手一首」三键（Tab 可达，支持 `prefers-reduced-motion`）。

**阅读体验（P0 + P1）**：

- 对比度按 WCAG AA 重算，浅色与暗色两套文字色实测均 ≥ 4.5:1（正文 ≥ 12:1）
- 全量键盘可达（列表项 `Tab` 聚焦、`Enter`/`Space` 打开）、`:focus-visible` 焦点环、可点目标 ≥ 44×44px、动效在 `prefers-reduced-motion` 下归零
- **阅读设置**：字号 16 / 18 / 20 / 22 四档、行距三档、衬线 / 黑体、竖排开关；主题三档（随境 / 浅 / 深）
- **独立阅读页** `#/poem/:id`：吸顶工具条（返回 / 诗题 / 元信息 / 繁简 / 竖排 / 字号）+ 34em 版心 + 底部上/下一篇
- **两套体裁排版**：古典整句居中、对句缩进，小序与注释降为小字带左侧竖线；现代诗保留原行断、长行悬挂缩进、节间空行，句前置创作年份。竖排只作用于正文并自动 +2px 字号
- 快捷键：`/` 或 `Ctrl+K` 检索 · `←` `→` 上一篇 / 下一篇 · `[` `]` 或 `PgUp` `PgDn` 翻页 · `Esc` 返回 / 关闭

修复：顶栏作者数改用全量口径并补现代诗数；浏览页朝代筛选由服务端数据生成（出现真实的「三国」，不再列 0 首的「隋」）；切篇不压栈（一次 `Esc` 回来路）；从阅读页返回列表恢复原滚动位置。

## 下载与使用

1. 到 [v1.2.0 下载页](https://github.com/xiwu0726/shihai/releases/tag/v1.2.0) 下载附件 `shihai.exe`（约 156 MB，文件名可随意改）
2. 放到任意文件夹，双击打开——不需要安装、不需要管理员权限、不需要联网
3. 关闭窗口即退出（只有你自己填的 AI Key 会存到 `%APPDATA%\shihai\ai-config.json`）

**系统要求**：Windows 10 / 11（64 位）

> 首次打开若弹出蓝色「已保护你的电脑」提示：这是 Windows 对未签名软件的正常拦截，点「更多信息」→「仍要运行」即可。

## 功能一览

- 全文搜索（毫秒级，支持多词）· 按朝代 / 体裁 / 作者 / 名句标签浏览（含「现代」朝代与「现代诗」体裁）
- 诗词详情页繁简切换、通行本异文对照、注释、简析、创作年份
- 作者小传与全部作品
- 阅读设置：字号 / 行距 / 字体 / 竖排；暗色模式（右上角「随境」按钮）；快捷键 `/` 或 `Ctrl+K` 检索、`←` `→` 翻页、`F11` 全屏
- AI 赏析 / 飞花令 / 对句 / 按心情荐诗（可选：在「设置」里填入你自己的 OpenAI 兼容网关 key，如 DeepSeek、智谱等；不填不影响阅读，key 仅存本机）

## 数据来源

- 古典部分：开源项目 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 全集，已做简繁整理、跨库去重、作者合并；名句标注来自唐诗三百首 / 宋词三百首 / 千家诗。
- 现代诗部分：开源语料库 [sheepzh/poetry](https://github.com/sheepzh/poetry)（MIT，3,489 位诗人 / 8.1 万首），另补录少量语料库缺失的传诵名篇（取公开通行本文本）。
