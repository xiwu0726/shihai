# 诗海 · 中国诗词全集（单机版 v1.1）

一个免安装的 Windows 桌面应用：内嵌 **42.0 万篇**（420,200 篇）诗词曲文、**1.6 万位**作者小传，从诗经到现代诗，支持全文搜索、繁简对照、名句标注、暗色模式。断网可用，所有内容都在这一个文件里。

## v1.1 新增：现代诗

收录 **8.1 万首华语现代诗**、**3,500+ 位现当代诗人**——徐志摩、戴望舒、卞之琳、艾青、冯至、穆旦、北岛、顾城、海子、舒婷、余光中、郑愁予、席慕蓉、林徽因、食指、余秀华……每首标注创作年份，海子《面朝大海，春暖花开》、食指《相信未来》等传诵名篇已核对补录。

## 下载与使用

1. 到 [Releases 页面](https://github.com/xiwu0726/shihai/releases) 下载最新版的附件 `shihai.exe`（约 150 MB，文件名可随意改）
2. 放到任意文件夹，双击打开——不需要安装、不需要管理员权限、不需要联网
3. 关闭窗口即退出，不在电脑中留任何文件

**系统要求**：Windows 10 / 11（64 位）

> 首次打开若弹出蓝色「已保护你的电脑」提示：这是 Windows 对未签名软件的正常拦截，点「更多信息」→「仍要运行」即可。

## 功能一览

- 全文搜索（毫秒级，支持多词）· 按朝代 / 体裁 / 作者 / 名句标签浏览（新增「现代」朝代与「现代诗」体裁）
- 诗词详情页繁简切换、通行本异文对照、注释、创作年份
- 作者小传与全部作品
- 暗色模式（右上角「随境」按钮）、快捷键 `/` 搜索、`←` `→` 翻页、`F11` 全屏
- AI 赏析 / 飞花令 / 对句 / 按心情荐诗（可选：在「设置」里填入你自己的 OpenAI 兼容网关 key，如 DeepSeek、智谱等；不填不影响阅读，key 仅存本机）

## 数据来源

- 古典部分：开源项目 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 全集，已做简繁整理、跨库去重、作者合并；名句标注来自唐诗三百首 / 宋词三百首 / 千家诗。
- 现代诗部分：开源语料库 [sheepzh/poetry](https://github.com/sheepzh/poetry)（MIT，3,489 位诗人 / 8.1 万首），另补录少量语料库缺失的传诵名篇（取公开通行本文本）。

**版权说明**：现代诗多为在版权作品，本应用收录的文本来自公开网络语料，仅供个人学习与欣赏，请勿用于商业用途；诗人或版权方如认为不妥，可联系下架，我们尊重并配合处理。
