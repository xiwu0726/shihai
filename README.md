# 诗海 · 中国古典诗词全集（单机版 v1.0）

一个免安装的 Windows 桌面应用：内嵌 **338,501 篇**诗词曲文、**13,186 位**作者小传，支持全文搜索、繁简对照、名句标注、暗色模式。断网可用，所有内容都在这一个文件里。

诗经 · 楚辞 · 曹操诗集 · 全唐诗（5.5 万首）· 全宋诗（25 万首）· 全宋词（2 万首）· 花间集 · 南唐二主词 · 元曲 · 纳兰词 · 论语 · 孟子 · 大学 · 中庸 · 三字经 · 百家姓 · 千字文 · 弟子规 · 增广贤文 · 朱子家训 · 声律启蒙 · 幼学琼林 · 古文观止（222 篇）· 千家诗 · 唐诗三百首 · 宋词三百首 · 幽梦影 ……

## 下载与使用

1. 下载下方附件 `诗海.exe`（约 130 MB）
2. 放到任意文件夹，双击打开——不需要安装、不需要管理员权限、不需要联网
3. 关闭窗口即退出，不在电脑中留任何文件

**系统要求**：Windows 10 / 11（64 位）

> 首次打开若弹出蓝色「已保护你的电脑」提示：这是 Windows 对未签名软件的正常拦截，点「更多信息」→「仍要运行」即可。

## 功能一览

- 全文搜索（毫秒级，支持多词）· 按朝代 / 体裁 / 作者 / 名句标签浏览
- 诗词详情页繁简切换、通行本异文对照、注释
- 作者小传与全部作品
- 暗色模式（右上角「随境」按钮）、快捷键 `/` 搜索、`←` `→` 翻页、`F11` 全屏
- AI 赏析 / 飞花令 / 对句 / 按心情荐诗（可选：在「设置」里填入你自己的 OpenAI 兼容网关 key，如 DeepSeek、智谱等；不填不影响阅读，key 仅存本机）

## 数据来源

开源项目 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 全集，已做简繁整理、跨库去重、作者合并；名句标注来自唐诗三百首 / 宋词三百首 / 千家诗。
